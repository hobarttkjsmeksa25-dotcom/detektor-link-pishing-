# Riset ciri-ciri URL phishing

- Memakai alamat IP, bukan nama domain
- Ada tanda @ di alamat (menyamarkan tujuan asli)
- Tidak memakai HTTPS
- Domain meniru brand (paypa1, g00gle, klik-bca-xxx)
- Mengandung kata pemancing: login, verifikasi, otp, hadiah
- Memakai pemendek URL (bit.ly) atau ekstensi domain berisiko (.xyz, .tk)
- URL sangat panjang atau subdomain berlapis
