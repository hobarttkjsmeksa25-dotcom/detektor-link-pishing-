# PhisGuard

Web app detektor link phishing berbasis Python (Flask).

## Tujuan
Menilai apakah sebuah URL mencurigakan dari bentuk alamatnya,
tanpa membuka URL tersebut.

## Rencana sesi
1. Memahami masalah dan riset ciri phishing
2. detector.py awal: HTTPS, IP, tanda @
3. Kata pemancing, TLD berisiko, pemendek URL, panjang URL
4. Peniruan brand, typosquatting, tes unit
5. Server Flask dan API
6. Tampilan web
7. Uji dengan link nyata dan finalisasi
